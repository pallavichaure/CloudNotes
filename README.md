# CloudNotes ☁️

CloudNotes is a cloud-based notes management application where users can create, edit, view, and delete notes.

## Features

- User Registration and Login
- Create Notes
- Edit Notes
- Delete Notes
- View Notes Dashboard
- Cloud Database Storage

## Tech Stack

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- AWS EC2
- AWS RDS

## Cloud Deployment

Application deployed on:

- AWS EC2 - Web Server
- AWS RDS MySQL - Database

## Project Architecture

User Browser  
↓  
AWS EC2 (Apache + PHP)  
↓  
AWS RDS MySQL Database
